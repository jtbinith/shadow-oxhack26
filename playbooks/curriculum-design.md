# Curriculum design

Build and adjust a routine's lesson tree.

- One lesson per **unique** 8-count; repeats are marked "same as 8-count k" and not taught twice.
- **Chaining:** learn A, learn B, then A+B; learn C, then A+B+C. Each joining step is a checkpoint.
- **Speed ladder:** every lesson has tiers 0.5× (bronze), 0.75× (silver), 1× (gold).
- Start at 0.5× when hit density or tempo is high, otherwise 0.75×.
- **Unlock:** pass (score ≥ 80) on 2 consecutive reps.
- Re-planning from the user's text: keep the order of the routine; change pace, review frequency
  and session length, never the choreography itself.
- Output only the `lesson_plan` JSON schema.
